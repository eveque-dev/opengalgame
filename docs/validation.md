## 范围

仅在本机 Windows x64 进行原生 UI 检查。云端测试不能替代实际显卡和声音设备上的交互体验。程序需要 OpenGL 3.3 驱动，当前无代码签名。

恢复间隔为 30 秒，可能丢失异常退出前最后一个周期的修改。新存档按最近 500 步的控制流程检查兼容；不保证任意剧情改写后的自动迁移。表情样例复用默认图，需作者自行替换为不同表情素材。

可复现数据性能记录见 [长篇性能](performance.md)，存档规则见 [兼容说明](save-compatibility.md)。这些数据计时不代表交互帧率或所有硬件表现。
