## 范围

仅在本机 Windows x64 进行原生 UI 检查。云端测试不能替代实际显卡和声音设备上的交互体验。程序需要 OpenGL 3.3 驱动，当前无代码签名。

恢复间隔为 30 秒，可能丢失异常退出前最后一个周期的修改。剧情改变后，存档可能因内容指纹变化而不能读取。表情样例复用默认图，需作者自行替换为不同表情素材。
