# 0.5 演出与制作指南

## 从样片开始

在项目中心点击“潮汐剧场 · 演出与配音”。内含 13 个节点、4 位角色、4 个结局和 13 段本地合成配音；9 条完整路径可达全部结局。四位角色复用已有两张演示立绘。要修改样片，建议先建立“独立副本”。

## 演出编排

选中节点后打开“演出”。拖动动作卡片排序，也可以使用上移、下移。支持人物入场、退场、移动与缩放、切换表情、等待、切换背景；动作顺序执行，单个时长 0～30 秒，每节点最多 128 个动作。移动与表情作用于已在舞台上的人物；人物未入场时不会自动出现。

“预览演出（无声）”在当前节点的初始舞台上播放；实际试玩会继承前一节点的舞台和持续音轨。动作结束后显示对白并开始逐句配音。减少动态效果会跳过视觉动画，保留作者设置的等待。基础场景淡入、滑入与动作可同时发生。

进入节点赋值只在到达时执行一次。推进时按“离开当前节点 → 选项赋值 → 进入目标节点”的顺序执行；任一步失败都会拒绝整次推进。显示条件在玩家看到的当前变量上判断。回退、读档直接恢复变量，不重复执行赋值。调试跳转跳过来源的离开操作，执行目标进入操作。

## 逐句配音与声音

在“演出 → 逐句配音”中选择已导入音轨。音乐、环境音、配音和短音效独立管理；音乐和环境音支持是否循环、音量、0～10 秒渐变和停止，短音效最多同时保留 8 个。配音期间可降低音乐音量。

“素材维护 → 批量匹配逐句配音”选择音频目录：以节点标识命名，例如 `opening.wav`。预览匹配结果后再导入；同名多个候选不会猜测。支持 WAV、MP3、OGG、FLAC。已有绑定会在确认后更新，工程仍需 Ctrl+S 保存。

玩家声音设置可独立调整四类音量、开关配音压低音乐，以及自动阅读是否等待配音结束。进入新节点会停止上一句配音和瞬时音效；回退、读档会恢复最终舞台并从头播放该句配音。对白回看可以单独重播，不改变剧情进度。

样片配音由 Windows 本地语音合成生成，音频文件随包提供；播放不需要额外安装语音包。生成脚本仅用于重新制作演示素材，不属于运行依赖。

## 主题与字体

在“主题”中启用作品独立主题，可选择海夜、纸与墨、樱色书笺三个起点。可编辑对话框底色、透明度、宽高、圆角、正文颜色和字号，姓名颜色、字号与底框，选项颜色、高度和字号，以及标题菜单位置、菜单底色、存档页 1～3 列。

微软雅黑、宋体、黑体使用 Windows 字体；也可导入 TTF、OTF、TTC，自定义字体随项目和游戏导出。预览与成品共用绘制代码；玩家自己的阅读字号仍可以覆盖作品默认字号。正文或选项较多时，在对话框中滚动阅读。

## 布局与表格

“布局与面板”可隐藏剧情目录、场景属性，打开宽屏条件编辑器，恢复默认布局。左右面板宽度、开关和表格列宽按项目保存在本机；不写入作品文件，不随导出共享。

表格拖动表头分隔线调整列宽，支持重置。文本格使用 Tab / Shift+Tab 在章节、标题、正文之间移动；Enter 移到下一段，Shift+Enter 在正文中换行，Ctrl+上下键在相邻段之间移动。

“复制所选行”按当前可见顺序复制七列：章节、类型、标题、发言人、正文、背景、下一节点，不含稳定标识与演出元数据。含制表符的粘贴按单元格批量应用，支持引号和多行正文；单列普通粘贴仍由文本编辑器处理。超出已有行、列，或引用无效时，整次批量粘贴不应用。节点标识、演出、配音和条件会保留；整次修改可以撤销。

## 分支与回归测试

“分支测试 → 运行全部测试”在后台探索当前开场可达的状态，并运行保存的用例。报告列出覆盖节点、选项、结局，未覆盖项目以及执行错误。未覆盖不等于不可达；默认上限 2000 个状态，可调整至 8192，每条自动路线最多 1000 步。达到上限会明确提示，不能据此声称穷举任意数值循环。

可以把自动找到的结局路线保存为用例，也可以在调试台录制后点击“保存本次试玩路线为用例”。从开场录制的用例会从当前版本开场重跑；中途录制的用例从记录的初始状态重跑。用例验证最终节点和完整变量，不做美术、主观音质或自然语言剧情判断。变量声明改变后需要复核或重新录制。最多保存 256 个用例。

报告记录对应工程指纹，修改工程后会提示重新运行。报告可导出 JSON。命令行可用于创作者自己的自动化：

```powershell
opengalgame.exe --test project.json test-report.json
```

错误或用例失败返回非零退出码。报告与用例不同：报告是某次检查结果，用例随工程保留。测试不会修改玩家存档和结局收藏。

## 素材维护与导出

素材标识更名会同步场景、演出、配音、声音指令和测试初始状态；新版本保留素材迁移映射，用于读取旧的舞台快照。素材文件另存新名称时会复制文件并更新引用，原文件保留供撤销。

缺失素材可以逐个重新定位，也可选择目录进行批量匹配。只有相同文件名的唯一候选会进入预览，冲突或未找到的文件留待手动处理。导入会校验素材类型；失败不会部分修改工程引用。已导入但未使用的文件可能保留在磁盘，后续可在清单中查看。

导出前显示素材占用、未用于场景的素材库条目、未被工程引用的磁盘文件与缺失项。正式导出包含素材库中登记的文件，磁盘上未引用的文件不导出；提示体积是素材原始文件合计，不是 ZIP 压缩后体积。

## 格式与兼容

0.5 可读取工程格式 1、2、3；使用演出、节点操作、主题或测试用例后保存为格式 3。新存档版本为 4，可读取真实 0.2、0.3、0.4 存档。修改已走过节点的进入／离开操作仍会触发流程兼容检查。美术动作可更新，读档时重建当前最终舞台。路线文件继续严格绑定录制时的工程内容；修改工程后需要重新录制路线。
