# OpenGalgame 0.8.1

- 背景素材卡分开显示图片、名称、标签和使用次数。窄窗口里按钮会换行。
- 导入或替换默认立绘与表情时，自动识别纯色底并生成透明 PNG。原图和已有透明区域的图片保留。
- 支持内嵌剧本与素材的单文件 Windows EXE、传统 Windows ZIP 和 Android APK。
- Windows 编辑器 ZIP 内置 ARM64 与 x86_64 Android 播放器。创作者需安装 JDK 和 Android SDK 才能生成 APK，玩家直接安装导出的文件。

建议下载 `opengalgame-v0.8.1-windows-x64.zip` 并解压运行。发布页提供《潮汐剧场》的三种格式供体验，以及源码和 SHA-256 校验文件。

[导出和 Android 环境说明](https://github.com/eveque-dev/opengalgame/blob/v0.8.1/docs/distribution.md)
