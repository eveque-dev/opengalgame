# OpenGalgame 0.2.0

首个以 **OpenGalgame** 名称发布的 Windows 版本：Rust 原生视觉小说引擎与可视化编辑器，从人物、对白与分支，到可独立运行的游戏。

## 下载

- **推荐：`opengalgame-v0.2.0-windows-x64.zip`**，解压后双击 `opengalgame.exe`。内附完整样例与组件许可，无需 Rust、Python 或 WebView。
- `three-letters-v0.2.0-windows-x64.zip`：三结局样例游戏，解压双击 `Game.exe`。
- `opengalgame-v0.2.0-source.zip`：源码、锁定依赖、文档、样例、测试与打包工具。
- `opengalgame.exe`：编辑器单文件，需以 `--editor project.json` 打开自己的现有项目。首次体验请下载完整便携包。
- `SHA256SUMS.txt`：发布文件校验值。

## 功能

对白批量导入、章节与全文替换、专注写作；端口拖线与条件分支；人物表情组与同屏演出；背景缩略图与引用计数；BGM/SFX 独立音量、转场、打字机；标题页、截图存档、阅读设置、结局收藏；自定义游戏背景与 EXE 图标；工程恢复与最近项目。

## 验证与兼容

21 项自动测试；42 节点、3 结局、10 条完整选择路径。目标 Windows 10/11 x64，需要 OpenGL 3.3 图形驱动。首版尚未覆盖全部设备，当前无代码签名，不支持 `.rpy` 导入和跨平台导出。

既有项目标识和剧情内容保留，旧数据目录可继续读取。修改剧情后，旧存档可能因指纹不同而被拒绝。
