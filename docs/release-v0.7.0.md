# OpenGalgame 0.7.0

在 Windows 编辑器里接入自己的模型服务，从场景对白继续写到可试玩的分支。

- **自带 API 密钥**。内置 DeepSeek、OpenAI、硅基流动和百炼预设，也支持自定义 OpenAI 兼容地址。密钥可由 Windows 加密保存在本机。
- **人物设定和前情**。角色定位、口吻、关系与前情随工程保存，可逐项勾选和预览发送内容。游戏导出会剔除作者资料。
- **大纲生成分支**。在预览中修改节点标题、正文、人物和跳转。校验通过后导入普通剧情节点，可为现有选择节点增加一个选项，也可一次撤销。
- **全剧一致性检查**。完整剧本分批检查，报告记录疑点、证据和修改建议，可定位原节点或复制。停止后保留已完成的批次。
- **编辑器配色**。可自由选取工作区底色与主色，也可切换预设并保存。

按 [AI 创作指南](https://github.com/eveque-dev/opengalgame/blob/v0.7.0/docs/ai-assistant.md) 配置连接。全剧检查的跨批判断会用到模型生成的摘要，疑点需要作者结合原文复核。

推荐下载 `opengalgame-v0.7.0-windows-x64.zip`，解压后双击 `opengalgame.exe`。发布页也提供单文件 EXE、三个独立游戏样例、源码包及 SHA-256 校验文件。
