# OpenGalgame 0.4.0

把复杂剧情写出来，也把每一次选择测清楚。

## 变量与条件

- 布尔、64 位整数、文本变量，保留原有布尔变量用法。
- 数值比较、文本/布尔相等判断，支持嵌套“全部满足 / 任一满足”。
- 可视化条件编辑与顺序赋值，整数增加/减少、文本/布尔设置。
- 类型错误、未知变量、整数溢出和无效目标不会留下部分赋值或推进剧情。

## 试玩调试台

- 观察与修改本次试玩变量，逐项查看选项显示/隐藏原因。
- 单步、回退、保留变量跳转、节点断点，运行到断点、选择或结局。
- 录制、导出、导入、重新复现路线，核对最终节点、变量和回退历史；命令行支持 `--replay`。
- 显示本次试玩观察到的节点与结局，测试变量不会写入玩家存档或结局收藏。
- 调试状态按项目独立；切换作品或失焦暂停自动执行。断点保留在本次项目标签内，路线可以导出后继续使用。

## 剧本表格

- 连续编辑章节、节点类型、标题、发言人、正文、背景与下一节点；可定位回场景编辑复杂选项。
- 全文搜索、多选、批量设置章节/发言人/背景、章节折叠，沿用撤销和工程恢复。
- UTF-8 CSV 导入导出，支持引号、逗号与多行正文；演出、条件、选项和音频配置完整保留。
- 导入先预览并校验，再按稳定标识更新/新增；未出现在 CSV 的节点保留，失败不应用。

## 兼容与样例

读取真实 0.2 与 0.3 存档，新增变量补齐默认值，类型和已走过条件改变会提示不兼容。新存档格式为 3；使用新增逻辑的项目格式为 2，需要 0.4 播放器。

附原创《灯塔来信》：三章、四位角色、五个结局、十二条完整选择路径，展示好感度、线索、承诺和文本条件。美术复用已有演示素材，四位角色暂共用两张立绘，可自行替换。

60 项自动测试，保留 5000 节点性能样例。验证范围见仓库 `docs/validation.md`。
