# OpenGalgame 0.3.0

多部作品，在同一个创作工作区继续。

## 项目中心与多任务

- 默认启动进入项目中心；新建空白故事或双结局模板，打开已有 JSON 项目。
- 作品搜索、置顶、阶段管理、归档、节点与字数统计，恢复上次打开的工作区。
- 多项目标签同时保留未保存内容、独立撤销/重做、选择节点和试玩进度。切换作品暂停自动阅读和音轨。
- 跨项目创作待办：待处理、进行中、已完成；按作品筛选，编辑标题和备注，随项目正式保存。
- 独立副本复制当前内容、待办和素材，生成新的作品标识，玩家存档互不混用。
- 后台导出队列使用提交时的内容快照；可以继续编辑其他作品、取消等待任务、查看失败原因与输出目录。
- 关闭项目和退出应用检查所有未保存项目；后台导出可等待完成再退出。

## 存档兼容

- 新存档根据最近 500 步及当前节点的控制流程检查兼容性。对白、标题、图片、布局与待办修改不再使整个存档失效。
- 节点改名自动记录迁移；新增变量为当前与回退历史补齐默认值。
- 已经过节点的类型、跳转、选择顺序、条件或赋值变化时拒绝直接读取，并提示原因。
- 读取 0.2 存档；第一次打开旧项目自动保存兼容基线，其他历史版本可以在项目设置导入当时的旧项目文件。
- 新版存档需要 0.3 播放器；不保证能在 0.2 程序中读取。兼容机制不等同于任意剧情重写后的自动迁移。

## 长篇性能

- 节点按标识索引；撤销快照共享未改动节点，单点编辑只复制被改动节点。
- 剧情目录与跳转选择按可见行绘制；分支图裁剪画面外节点、端口和连线，缓存循环检测。
- 图片后台解码，缩略图按需加载，GPU 图片缓存预算 96 MiB；切换项目清理非活动作品纹理。
- 恢复副本在后台序列化；放弃编辑会取消旧写入，避免已放弃的内容重新出现。
- 附可复现的 5000 节点、约 230 万字数据性能样例：`cargo run --release --example performance`。

## 下载

- **`opengalgame-v0.3.0-windows-x64.zip`**：推荐，Windows x64 便携编辑器，内附素材、样例、指南与许可。
- **`opengalgame.exe`**：单文件编辑器，双击即可进入项目中心并新建故事。
- **`three-letters-v0.3.0-windows-x64.zip`**：42 节点、3 结局的独立示例游戏。
- **`opengalgame-v0.3.0-source.zip`**：源码、依赖锁、测试与构建工具。
- **`SHA256SUMS.txt`**：发布文件校验值。

无需安装 Rust、Python 或 WebView。目标 Windows 10/11 x64，需要 OpenGL 3.3 图形驱动。详细验证范围见仓库 `docs/validation.md`。
