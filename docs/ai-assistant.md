# AI 创作与编辑器配色

打开工作台顶部的「AI 创作」，进入「连接设置」。选好服务，填入自己的 API 密钥和模型标识，再点「测试连接」。测试使用一条简短消息，服务商可能按用量计费。点「保存设置」后，下次打开仍会使用所选配置。

| 服务 | API 地址 | 默认模型 |
| --- | --- | --- |
| DeepSeek | 自动填写 | `deepseek-flash` |
| OpenAI | 自动填写 | `gpt-5-mini` |
| 硅基流动 | 自动填写中国站地址 | `deepseek-ai/DeepSeek-V4-Flash` |
| 通义千问 · 百炼 | 填入百炼控制台当前工作空间的 OpenAI 兼容地址，确保地址和密钥属于同一区域 | `qwen-plus` |
| 自定义兼容接口 | 填入 Base URL 或完整的 `/chat/completions` 地址，例如本机的 `http://localhost:11434/v1` | 按服务填写 |

模型标识都可编辑。远程接口使用 HTTPS。本机兼容接口可使用回环地址和空密钥。「加密保存密钥」可选，默认仅在当前会话中使用密钥。勾选后保存的密钥由当前 Windows 账户保护，并与接口地址绑定。若要移除保存的密钥，取消勾选并保存设置。

连接设置保存在本机用户目录。生成请求由编辑器直接发给所选服务，项目文件和导出的游戏包不含连接设置或密钥。

## 人物设定与前情

在「AI 创作 → 人物与前情」选择角色，填写定位与动机、说话方式、关系和已知事实，也可写一份作品的前情摘要。资料随作者工程保存。游戏导出会剔除这些作者资料，编辑或移除作者资料也不会改变路线复现指纹。

在「创作」「大纲分支」和「全剧检查」中展开「附带创作资料」，选择要随请求发送的人物卡，按需勾选前情摘要。资料默认不附带。发送前可展开内容预览。大纲分支和全剧检查还会发送项目中的人物姓名和标识，以便匹配角色。

## 润色和续写

打开要修改的场景，在「创作」中选择「润色对白」「续写对白」或「灵感草稿」。润色和续写会随创作要求发送当前节点标题与对白。灵感草稿默认只发送你输入的要求。生成后可直接编辑、复制，或用润色稿替换对白、用续写稿追加对白。若切换节点或原对白发生变化，回到原节点或重新生成后再写入。已写入的对白可用 Ctrl+Z 撤销。

## 从大纲生成分支

在「大纲分支」输入开场、关键选择和结局。生成后展开节点卡片，可修改标题、正文、发言人、选项文字、跳转与入口。模型 JSON 也可以手动修订并重新解析。导入前会校验人物引用、跳转、入口可达性以及通往结局的路线，单次最多导入 24 个节点。

「导入可编辑分支」将草稿添加到普通剧情工作台。默认导入为独立分支，可在分支图中连线。若选中现有选择节点，可在导入前为它新增一个通向草稿入口的选项。整个导入可一次撤销。

## 检查全剧

在「全剧检查」选择要附带的资料，点击「准备全剧检查」。程序会列出全部节点数和请求批次数。选定批次可预览剧本文字、跳转和变量，再点击「开始检查」。长篇按请求上限分批，后续请求会附上前一批整理的摘要。

报告列出人设、时间线、剧情事实或分支逻辑的疑点、证据和修改建议，可定位到具体节点，也可复制报告。检查不改写工程。跨批判断依赖模型生成的摘要，需结合原文复核。「停止后续批次」会保留已经返回的结果，当前请求会结束。连接失败或模型回复不完整时会显示已完成的批次和原因。

## 配色

点击工具栏「外观」可选择预设，也可以自由选取编辑器主色和工作区底色。编辑器根据输入色调整明暗以保持对比度。点击「保存配色」可在下次启动时恢复。作品的对话框、选项和存档页配色仍在项目的「主题」中编辑。
