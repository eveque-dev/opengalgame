# 0.4 创作与调试

## 变量与条件

在“变量”页添加故事变量。整数适合好感度、金钱、线索数量；文本适合角色名字或路线状态；布尔记录事件是否发生。原项目的布尔变量保留在“旧项目兼容布尔变量”中，也能在复合条件中引用。

在选择节点右侧展开“条件与变量 → 复合条件与数值赋值 · 0.4”，启用显示条件。可从单项比较切换为“全部满足（并且）”或“任一满足（或者）”，添加、移除或嵌套条件。例如：`affinity 大于等于 50`，并且 `read_letter 等于 真`。

整数支持相等、不等于、大于、大于等于、小于、小于等于；文本与布尔支持相等/不等于，不做自动类型转换。条件最多嵌套 8 层、128 项。文本变量最多 64 KiB；可视化字段最多输入 16384 个字符。

“选择后依次执行”添加赋值：整数可增加负数实现减少，或直接设置；布尔和文本可直接设置。旧“选择后改变变量”先执行，然后按顺序执行新增赋值。一次选择中任意赋值无效、溢出或目标缺失，会拒绝整次选择，不会产生半次修改。

引擎校验使用同一套条件和执行逻辑检查路径，最多检查 8192 个状态，超过会给出提示；这不代表已经穷举任意数值循环。

## 调试工作流

1. 打开“试玩调试台”，点击“从头开始并录制”，或先在舞台里开始试玩。
2. 用“单步前进”推进对白；选择节点会列出全部选项、当前值和显示条件，隐藏选项不能执行。
3. 在“变量观察 / 测试值”修改本次试玩状态；这不会改变工程初始值。测试状态不会写入玩家存档或结局收藏。
4. 选择跳转目标，点击“切换目标断点”；“运行到断点 / 选择”逐帧执行对白，到目标、选择或结局停下。可以提前暂停，切换作品和失焦也会暂停。
5. “带当前变量跳转”保留现有测试值，适合检查后续章节。回退同时恢复所有类型的变量。
6. 导出路线 JSON，包含初始状态、选择、测试赋值、调试跳转和回退操作。导入或重新复现时核对最终节点、变量和历史。

路线与录制时的项目内容严格匹配。编辑故事后需要重新录制；路线复现与玩家存档兼容是两套用途不同的检查。路线最多 10000 个操作，不运行任意脚本。观察节点/结局数量只表示本次执行的覆盖，不是所有分支都已验证。

断点与未导出的路线属于当前项目标签，关闭应用后不自动恢复；需要保留的路线请导出。多个项目各自记录，切换时不会混入另一个作品的变量。

```powershell
opengalgame.exe --replay project.json route.json
```

成功退出码为 0，格式、项目版本、操作或预期结果不符返回非零。不会覆盖工程或玩家存档。

完整包附 `examples/harbor-signals/route-promise.json`，可用上述命令复现“共同守灯”结局。源码中的 `cargo run --example record_route` 演示如何调用公开 API 录制这条路线。

## 表格与 CSV

点击“表格”，在同一列表中编辑对白和章节。多选后可批量设置章节、发言人、背景；空发言人表示旁白，空背景表示纯色舞台。章节可以折叠，搜索匹配标识、章节、标题、正文和选项文字。“场景”按钮回到节点属性，编辑分支选项和演出。

CSV 请从“导出 CSV”生成模板，使用 UTF-8 编码。列为：

| 列 | 说明 |
| --- | --- |
| 节点标识 | 稳定 ID，用于更新已有节点或新增节点；旧迁移标识不能复用 |
| 章节、类型、标题 | 类型填写“对白 / 选择 / 结局”，也接受英文枚举 |
| 发言人、背景 | 可以填已有标识或名称，留空表示无 |
| 正文 | 支持逗号、引号、换行，由 CSV 引号规则保护 |
| 下一节点 | 对白的目标标识；选择在场景或演出数据中配置 |
| 演出与选项 | 完整节点元数据，保留条件、赋值、选项、站位、表情、音轨与位置；通常不需要手动编辑 |

导入前必须预览，显示更新/新增数量。按标识更新，CSV 中没有的旧节点会保留；不会通过删除 CSV 行来删除剧情。引用、类型或条件有错误时不会应用。预览期间原工程若改变，需要重新预览，防止覆盖后来的修改。应用后可 Ctrl+Z，正式保存仍使用 Ctrl+S。

CSV 最多 20 MB、10000 个节点。新节点可以留空“演出与选项”并填写其他列；新增选择节点需在元数据中提供有效选项，或先在编辑器建立再导出。工程自身仍有 20 MB 文件限制。
