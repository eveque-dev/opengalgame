# OpenGalgame 0.5.0

从分支剧本，到有演出、有配音、可以回归验证的作品。

- **演出编排**：拖动排序、入场、退场、移动缩放、表情、等待、背景切换、时长和实时预览。
- **逐句配音**：音轨绑定、按节点标识批量匹配、回看重播、自动阅读等待语音结束。
- **四类声音**：音乐、环境音、配音、可叠加音效；循环、音量、淡入淡出与明确停止。
- **节点变量操作**：进入与离开时赋值；与选项赋值、目标进入操作一起事务提交，回退和读档不重复累加。
- **编辑布局**：面板开关、宽度和表格列宽按项目恢复；宽屏条件编辑器，表格键盘连续编辑、跨格复制粘贴。
- **游戏主题**：对话框、姓名框、选项、正文和字体、标题菜单、存档列数；支持自定义字体导出。
- **分支测试**：后台有界探索、覆盖报告、未测试分支定位、保存用例与一键重跑；命令行 `--test`。
- **素材维护**：标识更名同步引用与舞台迁移，文件另存名称保留撤销，缺失素材批量预览修复，导出体积与未使用清单。

新增《潮汐剧场》：13 个节点、4 位角色、4 个结局、9 条完整路径、13 段中文演示配音与 4 个回归用例。美术复用已有演示素材，配音使用 Windows 本地合成；运行无需安装语音包。

83 项自动测试，保留 0.2、0.3、0.4 固定旧存档兼容检查、原样例路径与长篇数据测试。新工程格式 3，新存档版本 4，需要配套更新播放器；旧工程和旧存档可继续读取。

## 下载

- `opengalgame-v0.5.0-windows-x64.zip`：推荐，便携编辑器、四个样例、指南和组件许可。
- `opengalgame.exe`：单文件编辑器，双击进入项目中心。
- `tidal-stage-v0.5.0-windows-x64.zip`：带配音与演出的四结局样片。
- `harbor-signals-v0.5.0-windows-x64.zip`：五结局变量样例。
- `three-letters-v0.5.0-windows-x64.zip`：原 42 节点三结局游戏。
- `opengalgame-v0.5.0-source.zip`：完整源码、锁定依赖、素材、测试和打包工具。
- `SHA256SUMS.txt`：发布文件校验值。

目标 Windows 10/11 x64，需要 OpenGL 3.3 图形驱动。运行无需 Rust、Python 或 WebView。
